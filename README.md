## Setup


1. Clone the repo and 'cd' into it.
2. Create a virtual environment:
'''

    python -m venv .venv
    source .venv/bin/activate

3. Install dependencies:
'''
    pip install -r requirements.txt
'''
4. Copy '.env.example' to '.env' and fill in your OpenAI API key
